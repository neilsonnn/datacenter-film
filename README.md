# datacenter-film

Films from the infiniband

## Setup

```
cd app
bun install
bun run dev
```

## Shots

- Drop images into a folder under `films/` 
- Describe the shot, audio, actions, etc. 
- Click Gen 1 or Gen 4 to submit

## Editing

- Click and drag left-to-right across a generated video to set its in and out points
- Add trimmed clips to a single global timeline
- Drop an audio file into the film's folder for soundtrack
- Export sends finished video to `exports/`
